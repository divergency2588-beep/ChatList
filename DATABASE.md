# Схема базы данных ChatList

Файл SQLite: `chatlist.db` в корне приложения.  
Доступ к БД инкапсулирован в модуле `db.py`.  
API-ключи **не хранятся** в базе: в таблице `models` указано только имя переменной из `.env`.

Временные результаты сравнения **не пишутся в SQLite**. Они живут в памяти, пока пользователь не нажмёт «Сохранить выбранные».

## Обзор

```
prompts 1 ──< results
models            (справочник нейросетей, без связи-FK на results)
settings          (ключ-значение)
logs              (журнал запросов, опционально)
```

## Таблица `prompts`

История запросов пользователя.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY, AUTOINCREMENT | Идентификатор промта |
| `created_at` | TEXT | NOT NULL | Дата и время создания (`YYYY-MM-DD HH:MM:SS`) |
| `prompt` | TEXT | NOT NULL | Текст запроса |
| `tags` | TEXT | NOT NULL, DEFAULT `''` | Теги (строка, например через запятую) |

Соответствует спецификации: дата, промт, теги.

## Таблица `models`

Справочник нейросетей.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY, AUTOINCREMENT | Идентификатор модели |
| `name` | TEXT | NOT NULL | Имя модели для API и для отображения (`gpt-4o-mini` и т.п.) |
| `api_url` | TEXT | NOT NULL | URL Chat Completions |
| `api_id` | TEXT | NOT NULL | Имя переменной окружения с ключом (`OPENAI_API_KEY`) |
| `is_active` | INTEGER | NOT NULL, DEFAULT `1` | `1` — участвует в рассылке, `0` — выключена |

Правило: `api_id` — это **не ключ**, а имя переменной из `.env`.

Активные модели выбираются так: `WHERE is_active = 1`.

Стартовые записи (создаются только если таблица пустая, по умолчанию выключены):

| name | api_url | api_id |
|---|---|---|
| `gpt-4o-mini` | `https://api.openai.com/v1/chat/completions` | `OPENAI_API_KEY` |
| `deepseek-chat` | `https://api.deepseek.com/v1/chat/completions` | `DEEPSEEK_API_KEY` |
| `llama-3.3-70b-versatile` | `https://api.groq.com/openai/v1/chat/completions` | `GROQ_API_KEY` |

## Таблица `results`

Постоянно сохранённые ответы. Записываются только строки временной таблицы с `selected = True`.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY, AUTOINCREMENT | Идентификатор результата |
| `created_at` | TEXT | NOT NULL | Дата сохранения |
| `prompt_id` | INTEGER | FK → `prompts(id)`, может быть NULL | Ссылка на исходный промт |
| `model_name` | TEXT | NOT NULL | Имя модели на момент сохранения |
| `prompt_text` | TEXT | NOT NULL | Текст промта (копия для просмотра и экспорта) |
| `response_text` | TEXT | NOT NULL | Текст ответа модели |

`prompt_text` дублируется специально: сохранённый результат остаётся читаемым, даже если запись в `prompts` позже удалят.

## Таблица `settings`

Настройки программы в формате ключ–значение.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `key` | TEXT | PRIMARY KEY | Имя настройки |
| `value` | TEXT | NOT NULL | Значение |

Стартовые ключи:

| key | value | Назначение |
|---|---|---|
| `request_timeout` | `60` | Таймаут HTTP-запроса, секунды |
| `temperature` | `0.7` | Параметр `temperature` для API |

## Таблица `logs`

Журнал запросов (дополнительная функция из спецификации).

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY, AUTOINCREMENT | Идентификатор записи |
| `created_at` | TEXT | NOT NULL | Дата события |
| `model_name` | TEXT | NOT NULL | Имя модели |
| `status` | TEXT | NOT NULL | `ok` или `error` |
| `message` | TEXT | NOT NULL, DEFAULT `''` | Краткий текст ответа или ошибки |

## Временная таблица результатов (не SQLite)

Хранится в памяти процесса, пока открыто окно или пока пользователь не сохранит / не отправит новый промт.

| Поле | Описание |
|---|---|
| `model_name` | Название модели |
| `response_text` | Текст ответа или сообщение об ошибке |
| `ok` | Успех запроса |
| `selected` | Чекбокс: сохранять ли строку в `results` |

Жизненный цикл:

1. Новый запрос — таблица удаляется целиком.
2. Приходят ответы — таблица создаётся заново.
3. «Сохранить выбранные» — строки с `selected = True` пишутся в `results`, память очищается.

## Связи и ограничения

- Включён `PRAGMA foreign_keys = ON`.
- `results.prompt_id` ссылается на `prompts.id`.
- Связи `results` → `models` нет: в результат копируется `model_name`, чтобы история не ломалась после правки справочника моделей.

## Что не хранится в БД

- API-ключи — только в `.env`.
- Текущие неотмеченные ответы сравнения — только во временной таблице в памяти.
